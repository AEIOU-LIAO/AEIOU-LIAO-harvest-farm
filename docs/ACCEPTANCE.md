## 三、浏览器端到端测试

脚本模拟两位玩家（A 用桌面尺寸，B 用 390×844 手机尺寸），控制台和页面错误均为 0：

1. A 打开首页，起名后“开始种田”，一键种满 6 块萝卜。
2. B 打开 A 的邀请链接，页面显示“阿花邀请你一起种菜”，B 进入后自动成为好友。
3. 服务器时钟快进 2 分钟，B 去 A 家串门，好友头像上显示 6 块可摘；一键摘取得到 8 个萝卜。
4. A 收到“小明摘走了你的 8 个萝卜（6 次）”的提示，一键收获得到 64 个（72 − 8）。
5. 逐个打开任务、好友、消息、仓库、商店、订单、集市、排行、成就、图鉴、装扮、设置、账号、玩法、资料各界面，均正常。
6. 注册账号后断网发起购买，出现断网条；恢复网络后自动重试，只扣一次款；刷新页面后数据保留。
7. 设为管理员后打开后台，数据概览、玩家详情、活动、数值配置、风控各页正常。

## 四、性能

本机压测：200 名玩家，每人 5 个好友，3000 次混合请求（读状态、好友列表、串门、一键摘取、一键收获、一键种植），50 个并发连接：

- 吞吐约 1100 次请求/秒，中位耗时 38 ms，95% 的请求在 88 ms 内完成
- 服务器错误 0 次，进程内存峰值约 125 MB（空闲约 75 MB）

## 五、未解决问题与建议

1. **上线方式需要你决定**：EdgeOne 静态托管不能运行服务端。推荐把 `farm.peiqi1.top` 指向你自己的服务器（README 方案 A）；如果要保留 EdgeOne 前端，需要给接口单独配置 HTTPS 域名（方案 B）。**v2 分支合并进 main 之前，接口服务要先部署好**，否则 EdgeOne 上的页面会连不上服务器。
2. 尚未在真机上测试（iOS Safari、安卓微信内置浏览器），也没有测试低端机的帧率。
3. Docker 镜像和 `deploy.sh` 写好了，但当前环境无法运行 Docker 和 systemd，**这两条部署路径没有实际跑过**。首次部署时请留意输出；`deploy.sh` 会在最后请求健康检查接口确认服务已启动。
4. 没有公会和社区合作目标；没有邮箱或手机号登录；没有验证码。
5. 偷菜的每日限制是次数（80 次），不是金币价值上限。
6. 旧存档不能精确迁移（浏览器数据可以被随意修改），只能领取一次有上限的礼包。
7. 赛季奖励需要玩家在下一周手动领取，不会自动发放。
8. 正式面向公众运营前，需要另行评估版号、实名认证、防沉迷和隐私合规。
9. NPC 对玩家不公开身份。若将来加入充值，用不公开身份的机器人影响真人消费可能涉及消费者保护和反不正当竞争方面的风险，届时请专业人士评估。
10. 3D 画面没有在真实手机和显卡上测过帧率，首次上线后请用常用机型实际体验一次。

## 六、上线后建议关注的指标

后台“数据概览”中可以直接看到：好友添加率、偷菜参与率、次日和七日留存、订单完成率、接口错误率和平均耗时、页面平均加载耗时。上线第一周建议重点看好友添加率。如果大多数玩家没有好友，偷菜玩法就无法展开，这时应优先强化邀请入口（例如给邀请成功的双方发奖励）。

## 九、EdgeOne Pages + Turso 部署（v2.2）

服务端改为与运行平台无关的请求处理核心（`server/app.js`）。自己的服务器用 `server/index.js` 包一层；EdgeOne 用 `cloud-functions/api/[[default]].js` 包一层。数据库层同一套异步接口，背后可以是本地 SQLite，也可以是 Turso。

### 部署前自查

| # | 问题 | 结论与处理 | 验证 |
|---|---|---|---|
| 1 | Node 版本：原代码依赖 Node 22 的 `node:sqlite` | EdgeOne 路径完全不加载 `node:sqlite`（只在本地 SQLite 后端的函数内部按需加载）。用到的接口（`fetch`、`structuredClone`、`AsyncLocalStorage`、`crypto`）Node 18 起都有。云函数目录单独声明为 ESM，平台打包或不打包都能加载 | CI 在 Node 18 / 20 上加载入口并调用一次 `onRequest`；本机 Node 22 下入口测试通过 |
| 2 | 数据持久化：云函数本地文件会丢 | 数据全部存在 Turso（托管的 SQLite 兼容数据库，跨实例共享、持久保存）；云函数实例里只有可以随时丢弃的缓存。表结构在冷启动时自动创建，已是最新版本时不加锁、不写入 | 入口测试：两个独立实例连同一个数据库，看到的金币一致；导出 → 导入新库 → 再导出，28 张表逐行一致 |
| 3 | 并发一致性：多人同时偷菜、交易不能重复结算 | 每个请求一个数据库事务。写操作在实例内排队，并以排他锁执行（`BEGIN IMMEDIATE`）；跨实例由数据库写锁保证，拿不到锁会短暂等待重试（最多约 10 秒），事务内不会出现半成功。幂等键与业务写入在同一事务。扣金币、扣库存、领奖、偷菜去重都有数据库约束兜底（`CHECK` / `UNIQUE`） | 16 组接口测试在模拟 Turso 上全部通过，包括“40 个请求并发偷同一块地”和“并发购买只成交一次”。压力测试：两个实例、10 人同时互偷 4 轮、30 个写请求同一瞬间到达，零错误，每人金币等于账本合计，偷到总量等于被偷总量，没有重复偷、没有负库存 |
| 4 | NPC 定时任务：没有常驻进程 | 在线玩家的页面每分钟顺手调用一次 `/api/cron`；`edgeone.json` 的 `schedules` 每天一次做数据清理（EdgeOne 免费版定时任务最短间隔一天，每分钟一次会被拒绝）。数据库租约保证同一时间只运行一份，间隔多长就按多长折算 NPC 上线概率；每个 NPC 动作各自一个小事务，不会长时间占用写锁；单次最多运行约 25 秒（函数上限设为 60 秒） | 入口测试：定时任务生成并运行 NPC，另一个实例同时触发会跳过；浏览器联测中触发成功 |
| 5 | 服务端入口：原来是 `server.listen()` | 新增 EdgeOne 入口，导出 `onRequest(context)`，把 Web Request 转成统一格式交给核心，返回标准 Response；环境变量从 `context.env` 读取；同一实例复用初始化结果 | 入口测试按 EdgeOne 的调用方式覆盖初始化、缺少配置时的提示、注册、游戏操作、定时任务 |
| 6 | 账号与登录：Cookie、登录状态、多设备 | 页面和接口在同一个 EdgeOne 域名下，不存在跨域 Cookie 问题；`hf_dev` 为 HttpOnly、SameSite=Lax、仅发往 `/api`，HTTPS 下带 Secure。登录状态和存档都在数据库里，任何设备、任何实例看到的都一样 | 入口测试：HTTPS 下 Cookie 带 Secure；只凭 Cookie 的“另一台设备”能列出并进入账号、看到同样的作物。浏览器联测（后端为带 50 毫秒延迟的模拟 Turso）：多账号自动进入、清空存储后自动进入、切换、退出、点头像进入全部正常，页面零报错 |
| 7 | 其他：文件读写、定时器、并发、备份 | 云函数路径不读写本地文件、不依赖定时器（限流器的清理定时器已 `unref`，不影响函数结束）；统计指标在内存累计，随后续请求在事务外写入，不制造冲突；在线时间等“顺手写”放到事务提交后。备份：Turso 自带；另外新增 GitHub Actions 每日导出（`.github/workflows/backup.yml`，保留 30 天）和 `server/cli.js dump / load` 命令 | 导出、导入、再导出逐行一致；遗漏的异步错误只记录不退出（压力测试中发现并修复了一处） |

### 首次部署问题与修复（2026-10-24）

- 现象：页面提示“服务器返回异常”，`/api/health` 返回首页。
- 原因：EdgeOne 构建云函数时会改写入口文件的 `import` 路径，入口引用 `../../server/app.js` 时改写失败（构建日志 `Failed to transform paths`），函数没有正确生成，`/api` 请求回落到静态首页；同时每分钟一次的定时任务超出免费版限制。
- 修复：入口改为自包含的打包文件（`deploy/bundle-functions.js` 生成），不含任何 `import` 声明，内置模块运行时加载；定时任务改为每天一次；新增零依赖的 `/api/ping` 诊断接口；前端遇到接口返回网页时明确提示“接口没有部署成功”。

## 十八、v2.9.2：狗狗不再“滑行”、不再木讷

| 问题 | 原因 | 处理 |
|---|---|---|
| 四条腿在漂移 / 滑行 | 腿按固定频率摆动，和实际走的速度无关；巡逻是匀速绕圈、说停就停 | 步伐改为按**真实走过的距离**推进：着地的脚在地面上匀速向后、速度和身体前进速度一致，并补偿腿斜着时的高度，脚掌贴地；速度慢步子小、速度快步子大 |
| 步态单一 | 只有一种摆腿 | 按速度自动切换三种步态：慢走（四拍，一条腿一条腿迈）→ 小跑（对角线）→ 奔跑（前腿一起、后腿一起，身体前后起伏），切换时平滑过渡；抬腿时腿收短像弯膝 |
| 动作生硬 | 原地瞬间转身、匀速移动 | 移动有加速、减速、转向速度限制：先转身再走，快到了慢慢停；转弯时身体向内侧倾 |
| 木讷 | 只会绕圈 | 看家时随机切换行为：站着东张西望、低头闻地面（鼻子一点一点）、小跑溜达、坐下、趴着、突然撒欢跑一圈再跑回来；漫游时主人走到狗窝这边，狗会跑过来迎接、看着主人、尾巴摇得更欢；牧羊时远了狂奔、近了放慢压低身子“盯羊”（边牧特有的低姿态），休息时趴下 |
| 头和尾巴 | — | 头会转向想看的东西（主人、羊、远处），身体起伏时头保持平稳；尾巴摇摆速度和幅度随兴奋程度变化，跑起来抬高，“盯羊”时压低 |

验证：脚着地阶段的位移约为身体位移的 15%（原来腿的摆动与移动无关，基本一直在滑）；牧羊循环回归测试通过。
